This is my own completed implementation of the CCNA Mega lab from Jeremysitlab.
I have completed it independently as part of my CCNA studies and hands on networking practice.
This lab covers a broad range of CCNA-level networking concepts including: 
<br>
(Vlans,Trunking,RSTP,Layer 2/3 Etherchannels,IPv4/IPv6,DHCP,DHCP snooping,OSPF,Standard+Extended ACLs,HSRP,Dynamic Arp Inspection,NAT, Wireless etc) 
<br>

#### IMPLEMENTATION: My own configuration and troubleshooting
#### TOOL: Cisco Packet Tracer

### How to Use the Lab 
<br>
To use this lab:
<br>
1: Download the .pka file from the repository
<br>
2: Open the download file using Cisco Packet Tracer 

###### It is recommended to use the latest version of Cisco Packet Tracer. Older versions may not be able to open or properly run the files created with newer versions of Packet Tracer
3: Explore the topology and configurations.
<br>
4: Test connectivity and verify the configured technologies.
